# ⚽ Women's Football Data Pipeline & Analytics App

> **Increasing accessibility to women's football data and analytics.**

Women's football data can be difficult to locate and often feels secondary to men's data. This project was built to centralize women's football datasets, streamline data pipelines, and provide interactive analytics to make women's football data more accessible to fans, analysts, and developers.

---

## 🚀 App

Check out the streamlit app:  
**[Women's Football Data App](https://maddiew22-womens-football-data-pipeline-appapp-jpedtz.streamlit.app/)**

---

## ✨ Features

- **Automated Data Pipeline:** Regularly scrapes data from popular sources including fotmob, sofascore, and statsbomb. Cleans and standardizes data from these different sources to create robust women's football datasets across multiple leagues (including the WSL (England), NWSL (USA), Women's Champions League, Frauen Bundesliga (Germany), Liga F (Spain), Premiere League Feminine (France), Serie A Femminile (Italy), WE-League (Japan), Damallsvenskan (Sweden), Brasileirão Série A (Brazil), A-League Women (Australia), Toppserien Women (Norway), Campeonato Nacional Feminino (Portugal), as well as international tournaments)
- **Streamlit App:** Access in depth player stats and analyses, compare player profiles, explore inter-league stats leaderboards
- **Data API:** API endpoints to easily access  structured women's football data.

---

## 🛠️ Built With

- **Fullstack:** Streamlit (frontend), Python and FastAPI (backend)
- **Data Engineering and Processing:** Databricks, Web scraping (BeautifulSoup/Selenium), Pandas and NumPy
